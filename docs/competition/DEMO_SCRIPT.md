# Competition Demo Script — 같이갈개

**Duration:** 4–5 minutes  
**Dataset:** deterministic sanitized fixture  
**Rule:** never describe the deterministic fixture as a live venue guarantee; describe live API verification as integration evidence only

## Setup

1. Run `npm install`, then `npm run build && npm start`.
2. Open the service at 390px mobile width or a mobile browser.
3. Confirm the header says `검증용 데이터 · 2곳`.
4. Keep network access optional; the judged behavior does not depend on upstream availability.

## Script

### 1. State the decision problem — 20 seconds

“A broad pet-friendly label is not enough. This service returns a place only when every selected requirement is supported by source evidence.” Point to the AND, proof, and unknown principles above the controls.

### 2. Prove exact matching — 40 seconds

Keep `소형견`, `목줄 착용 가능`, and `이동가방 이용 가능` selected. Show `정확히 1곳` and open `선택한 조건 3개 근거 보기` on `파도끝 테라스`. Count the three proof rows and identify the source excerpt/link.

### 3. Prove safe recovery — 50 seconds

Select `중형견`. Show `정확히 0곳` and the explicit proposal to remove only the carrier preference. Press `이 선호만 빼고 보기`; verify `솔바람 산책정원` appears. Then select `대형견` and show that no automatic hard-constraint relaxation is offered.

### 4. Prove the exact-only course — 50 seconds

Return to `소형견`; the carrier preference remains removed, producing two exact results. Press `가까운 순서로 코스 만들기`. Show both stops, the proof count, `근거리 순서 · 대략`, straight-line distances, and the absence of any minute estimate. Explain that the map link is a routing handoff, not route evidence generated by this product.

### 5. Prove nearby honesty — 45 seconds

Show `동반·이용 확인됨` separately from `반려동물 정책 확인 필요`. Emphasize that proximity never implies pet compatibility. Press `내 위치로 다시 계산`; if permission is unavailable, show the named reference-place fallback. State that precise location is requested only on this action and is not persisted.

### 6. Close with the data story — 30 seconds

Summarize: official provider boundary → validated raw snapshot → conservative tri-state normalization → strict AND result → source proof → safe optional course. Disclose that the judged flow uses sanitized deterministic evidence; issued-key integration is separately verified, while venue truth and freshness still require confirmation.

## Fallback

- If the browser fails, use screenshots under `devlog/_fin/260716_mvp_implementation/evidence/` in numeric order.
- If location permission behavior differs, explain both success and denial copy; the automated test proves the denial fallback.
- Never switch to an unvalidated live refresh during the judged core flow.
